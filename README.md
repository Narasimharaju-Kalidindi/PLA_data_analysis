# PLA Image Quantification Data Analysis Using R

## Description

This R script automatically calculates PLA signal values from the output
files generated by the MATLAB-based PLA image quantification pipeline.

The script reads the **Cell Labels** and **Puncta Statistics** CSV files
generated by MATLAB and calculates PLA signal for each image using the
following formula:

**PLA Signal = Σ(Area × Mean Intensity) / Total Cell Count**

where: - Area = puncta area (pixels) - Mean Intensity = mean
fluorescence intensity of each punctum - Total Cell Count = number of
segmented cells identified by MATLAB

## Requirements

-   R (version 4.0 or later)
-   MATLAB output folder containing:
    -   Cell Labels CSV files
    -   Puncta Statistics CSV files

## Usage

1.  Open R or RStudio.
2.  Run the script:
    `R code for PLA signal for all raw images in ML data folder.R`
3.  When prompted, select the MATLAB Output folder containing the Cell
    Labels and Puncta Statistics CSV files.
4.  The script will automatically:
    -   Match Cell Labels and Puncta Statistics files for each image.
    -   Calculate total puncta intensity.
    -   Normalize puncta intensity to cell number.
    -   Generate PLA signal values for all analysed images.

## Output

The script generates:

`Results/PLA_Output.csv`

containing:

  Column           Description
  ---------------- -----------------------------
  Raw_Image_Name   Original image name
  PLA_Signal       Normalized PLA signal value

## Downstream Analysis

Import `PLA_Output.csv` into GraphPad Prism for: - Data visualization -
Fold-change calculations - Statistical analysis
